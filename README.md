# Haven Check-in Call Notes

Detailed notes and machine-generated transcripts of the weekly **Hack Club Haven** organizer check-in calls (calls #2–#7) and the workshops that followed some of them, written up by Ingo Wolf's assistant for the Canberra satellite game jam (14–15 Nov 2026).

- `notes/` — **detailed** organizer notes per call, meant to be a real alternative to attending: a TL;DR, an action-item checklist, a section-by-section walkthrough with timestamps, key numbers, links and Q&A. Where audio was unclear it is marked `[unclear]`. Times are given in UTC, Canberra time (AEST/AEDT) and US Eastern time.
- `transcripts/` — full timestamped transcripts. These are **machine-generated** (faster-whisper `medium.en`) and may contain errors; speakers are not labelled.
- Workshops get their own notes file. Where a workshop was recorded in the same file as its call (calls #3 and #5), both notes link to the same transcript.
